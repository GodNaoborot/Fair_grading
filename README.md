# Fair grading

Байесовская модель в духе IRT (Item Response Theory), разделяющая два вклада
в оценку студента: его собственную подготовку и сложность предмета.

Средний балл сравнивает студентов, учившихся на разных предметах, так, как
будто предметы одинаковы: пятёрка по курсу, где пятёрки у всех, и четвёрка по
курсу, где преобладают тройки, весят в нём одинаково. Модель оценивает по
матрице оценок две латентные величины — способность студента `s ∈ [0, 1]`
и сложность предмета `d ∈ [0, 1]` — так, чтобы вероятности оценок 2–5 в
каждой ячейке наилучшим образом объясняли наблюдаемые данные. Результатом
является апостериорное распределение, а не точечная оценка.

```
              data/grades_sem*.csv        138 студентов x 6 и 10 предметов
                        │
          compute_chi_priors.py           приор сложности из формы
                        │                 распределения оценок
            run_mcmc_chi_prior.py         NUTS, 16 трасс
                        │
    ┌─────────────┬─────┴───────┬─────────────────┐
diagnostics.py validate.py  query.py    plot_ratio_comparison.py
r_hat / ESS    LOO + PPC    запрос по   сравнительные графики
дивергенции                 студенту    формул ratio
                            и предмету
```

## Установка и запуск

```bash
python -m venv .venv
.venv\Scripts\activate          # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```

```bash
python scripts/compute_chi_priors.py    # приоры сложности -> data/chi_priors.json
python scripts/run_mcmc_chi_prior.py    # MCMC             -> results/traces/*.nc
python scripts/diagnostics.py           # сходимость       -> results/diagnostics.csv
python scripts/validate.py              # LOO и PPC        -> results/loo_compare_*.csv
```

Посчитанные трассы переиспользуются, повторный запуск их не пересчитывает.
Ключи `--sem`, `--ratio`, `--model` ограничивают прогон нужной частью,
`--quick` включает черновые настройки сэмплера. Семейства правдоподобия
`tilted` и `ordered` в базовый прогон не входят и запрашиваются явным
`--model`.

### Возможные проблемы окружения

Если при запуске `query.py` или `diagnostics.py` возникает

```
found the following matches with the input file in xarray's IO backends:
['netcdf4', 'h5netcdf']. But their dependencies may not be installed
```

в окружении отсутствует движок чтения netCDF. Устраняется установкой
`h5netcdf` (входит в `requirements.txt`); при установке `arviz` из
conda-канала он не всегда подтягивается автоматически.

Версии `pymc` и `arviz` заданы в `requirements.txt` намеренно. Код проверен
на `pymc 5.28` и `arviz 0.23`; на `pymc 6.x` он загружает трассы и отвечает
на запросы, но построение моделей (`run_mcmc_chi_prior.py`, `validate.py`)
не тестировалось.

### Выбор сэмплера

По умолчанию используется nutpie (`--sampler nutpie`) — реализация NUTS,
компилирующая модель через numba. Родной бэкенд PyTensor требует
C++-компилятора; без него граф исполняется интерпретатором Python, и время
одной трассы возрастает с десятков секунд до величин, непригодных для работы.
Родной бэкенд доступен через `--sampler pymc`.

## Модель

Для каждой наблюдаемой пары (студент `i`, предмет `j`) вычисляется скаляр
совпадения `r ∈ [0, 1]`, из которого определяются вероятности четырёх оценок.

### Приоры

`s ~ Beta(2, 2)`. `d ~ Beta(α_j, β_j)`, где центр приора для каждого предмета
берётся из chi-square оценки сложности (см. ниже), а концентрация
фиксирована: `α + β = 4`, что соответствует «силе» приора `Beta(2, 2)`.

### Формулы совпадения

Задаются параметром `ratio_kind`:

| вариант | формула | свойства |
|---|---|---|
| `legacy_sd` | `s / (s + d)` | симметрична, при `s = d` равна ½ |
| `current` | `1 − d(1 − s)` | асимметрична: равна 1 и при `d = 0`, и при `s = 1` |
| `sigmoid` | `σ(k(s − d))`, `k = 5` | симметрична, гладкая, резкость задаётся `k` |

Ожидаемое поведение модели в характерных точках:

| s | d | сценарий | ожидаемая оценка |
|---|---|---|---|
| 0 | 1 | слабый студент, сложный предмет | 2 |
| 0.5 | 0.5 | средний студент, средний предмет | 3–4 |
| 1 | 0 | сильный студент, лёгкий предмет | 5 |
| 0 | 0 | слабый студент, лёгкий предмет | 3–4 |
| 1 | 1 | сильный студент, сложный предмет | 3–4 |

Проверка формул по этим точкам приведена в
[`notebooks/model_comparison.ipynb`](notebooks/model_comparison.ipynb).
`legacy_sd` и `sigmoid` соответствуют ожиданиям; `current` смещает среднюю
точку к 4–5 и отображает углы `(0,0)` и `(1,1)` в одно значение `r = 1`.

### Семейства правдоподобия

Доступны четыре варианта, выбираются параметром `--model`.

**`nocond`** — вероятности задаются фиксированным семейством, нормированным
по построению (`f_2 + f_3 + f_4 + f_5 ≡ 1`):

```
f_2(x) = (1−x)³ / ((1−x)³ + 10x²)      f_5(x) = f_2(1 − x)
f_3(x) = (1−x) · (1 − f_2(x) − f_5(x)) f_4(x) = f_3(1 − x)
```

Оценка ~ `Categorical(f_2(r), f_3(r), f_4(r), f_5(r))`.

**`cond`** — то же семейство плюс «гейт», смещающий уверенные случаи к
крайним оценкам:

```
P = p_5 · [0.001, 0.001, 0.001, 0.997]
  + p_2 · [0.997, 0.001, 0.001, 0.001]
  + (1 − p_5 − p_2) · [f_2(r), f_3(r), f_4(r), f_5(r)]
```

где `p_5 = σ(t(r − hi))`, `p_2 = σ(t(lo − r))`. Значения по умолчанию:
`lo = 0.3`, `hi = 0.7`, `t = 15`. Пороги смещены внутрь шкалы: при значениях
`0.1 / 0.9` гейт активен только там, где `f`-функции и без него дают 0.997,
и `cond` численно не отличается от `nocond`. Влияние текущих порогов:

| сценарий | `nocond` | `cond` |
|---|---|---|
| хороший студент, средний предмет | E = 4.17 | E = 4.67 |
| средний студент, средний предмет | E = 3.50 | E = 3.50 |
| слабый студент, средний предмет | E = 2.83 | E = 2.33 |

При `s = d` оценки 3 и 4 остаются наиболее вероятными (по 0.41).

**`tilted`** — форма `f_k` сохранена, но умножается на свободные веса:
`p_k ∝ w_k · f_k(r)`, где `w ~ Dirichlet(1, 1, 1, 1)`. Три дополнительных
параметра, задающих распространённость каждой оценки независимо от `r`.

**`ordered`** — порядковая логистическая модель (graded response):
`z = logit(r)`, пороги `c1 < c2 < c3`, `P(оценка ≤ k) = σ(c_k − z)`.

Средний порог закреплён в нуле, свободны два зазора. Это ограничение снимает
ненаблюдаемость: прибавление константы ко всем трём порогам с одновременным
сдвигом `s` даёт идентичное правдоподобие, из-за чего апостериорное
распределение вырождается в плоский хребет. Со всеми тремя свободными
порогами модель не сходилась (`r_hat = 1.53`, `ESS = 8` на семестре 2);
после закрепления — `r_hat = 1.003`, `ESS = 1304`, дивергенций нет. Общий
уровень строгости при этом поглощается латентными `s` и `d`.

## Chi-square приор на сложность

Плоский `Beta(2, 2)` для всех предметов не учитывает, что распределение
оценок по сложному предмету имеет иную форму, чем по лёгкому.
`chi_square_difficulty` измеряет χ²-расстояние от эмпирического распределения
оценок предмета до двух эталонов:

```
score = χ²(эмпирика, эталон_лёгкого) / (χ²(…лёгкого) + χ²(…сложного))
```

Полученное значение из `[0, 1]` становится центром `Beta`-приора для этого
предмета. Подбор эталонов приведён в
[`notebooks/chi_square.ipynb`](notebooks/chi_square.ipynb).

## Сходимость

Проверяется `scripts/diagnostics.py`, результат сохраняется в
`results/diagnostics.csv`. Пороги: `r_hat ≤ 1.01`, `ESS ≥ 400`.

Сходятся 15 трасс из 16. Дивергенций нет ни в одной конфигурации.
Не сошлась `sem2 · tilted · sigmoid` (`r_hat = 1.025`, `ESS = 120`),
её показатели в сравнении ниже помечены как ненадёжные.

Настройки, при которых получены текущие трассы:

| набор | настройки |
|---|---|
| `cond`, `nocond`, все ratio | `draws=4000, tune=2000, target_accept=0.95` |
| `sem2 · cond · sigmoid` | `draws=8000, tune=6000, target_accept=0.99` |
| `tilted`, `ordered` | `draws=4000, tune=4000, target_accept=0.99` |

Наибольшие затруднения вызывает `sigmoid`. Расходится не способность
студентов, а сложность предметов: параметров мало, наблюдений на каждый
много, апостериорное распределение узкое и медленно перемешивается. Число
draws и tune устраняет проблему; отсутствие дивергенций указывает на то,
что геометрия задачи для NUTS приемлема.

Воспроизведение:

```bash
python scripts/run_mcmc_chi_prior.py --draws 4000 --tune 2000 --chains 4 --cores 4
python scripts/run_mcmc_chi_prior.py --sem 2 --model cond --ratio sigmoid \
    --draws 8000 --tune 6000 --target-accept 0.99
python scripts/run_mcmc_chi_prior.py --model tilted --model ordered --ratio sigmoid \
    --draws 4000 --tune 4000 --target-accept 0.99
python scripts/diagnostics.py
```

## Валидация

Сходимость подтверждает лишь корректность работы сэмплера. Сравнение
конфигураций выполняет `scripts/validate.py` тремя способами: PSIS-LOO,
предсказательная точность на наблюдённых оценках и posterior predictive
check. LOO вычисляется отдельно по каждому семестру, поскольку сопоставим
только между моделями, обученными на одних наблюдениях.

### LOO

`results/loo_compare_sem{1,2}.csv`:

| конфигурация | elpd сем 1 | место | elpd сем 2 | место | плохих Парето-k |
|---|---|---|---|---|---|
| `tilted` + `sigmoid` | −611.3 | 0 | −983.4 | 2 | 10 / 6 |
| `nocond` + `current` | −625.9 | 1 | −977.8 | 1 | 12 / 7 |
| `nocond` + `sigmoid` | −630.6 | 2 | −992.9 | 3 | 7 / 6 |
| `ordered` + `sigmoid` | −637.6 | 3 | −974.7 | 0 | 2 / 2 |
| `cond` + `current` | −656.0 | 4 | −1005.5 | 4 | 18 / 10 |
| `cond` + `sigmoid` | −661.6 | 5 | −1018.3 | 7 | 14 / 8 |
| `nocond` + `legacy_sd` | −663.1 | 6 | −1015.9 | 6 | 3 / 1 |
| `cond` + `legacy_sd` | −664.7 | 7 | −1013.8 | 5 | 7 / 3 |

Гейт снижает предсказательную способность: все конфигурации с `cond`
уступают аналогам без гейта с отрывом 30–44 elpd при `dse` 9–13.

Разрывы между лидерами статистически незначимы. На семестре 1 `tilted`
опережает `nocond` + `current` на 14.6 при `dse` 9.0, на семестре 2
`ordered` опережает на 3.0 при `dse` 9.9 — в обоих случаях менее двух
стандартных ошибок.

Столбец `bad_pareto_k` отражает число наблюдений с Парето-k > 0.7, для
которых LOO-аппроксимация не гарантирована. У `ordered` таких наблюдений
2 против 6–18 у остальных, то есть его оценка наиболее надёжна.

### Предсказательная точность

Вероятности, вычисленные так же, как их выдаёт `query.py`, с маргинализацией
по постериору (`results/predictive_scores.csv`). Метрики выборочные — модель
эти оценки видела, — поэтому дополняют LOO, но не заменяют его.

| сем | конфигурация | log_pred | accuracy | MAE |
|---|---|---|---|---|
| 1 | `tilted` + `sigmoid` | −0.713 | 0.699 | 0.424 |
| 1 | `nocond` + `sigmoid` | −0.755 | 0.668 | 0.426 |
| 1 | `ordered` + `sigmoid` | −0.808 | 0.671 | 0.501 |
| 2 | `tilted` + `sigmoid` | −0.820 | 0.651 | 0.479 |
| 2 | `nocond` + `sigmoid` | −0.836 | 0.617 | 0.480 |
| 2 | `ordered` + `sigmoid` | −0.859 | 0.637 | 0.514 |

Порядок расходится с LOO: по этой метрике лидирует `tilted`. Расхождение
согласуется с величиной `dse` — данные не разделяют ведущие конфигурации
уверенно, и знак разницы зависит от выбранной метрики.

### Posterior predictive check

Из постериора разыгрываются новые комплекты оценок, их распределение
сравнивается с фактическим (`results/ppc_summary.csv`,
`results/plots/ppc_sem{1,2}.png`). Проверяется попадание фактической доли
каждой оценки в 94% интервал модели.

Фиксированное семейство `f_2..f_5` воспроизводит форму распределения плохо —
2 попадания из 8 у `nocond` + `sigmoid`, 3 из 8 у `cond` + `sigmoid`.
Отклонения системные (семестр 1, процентные пункты):

| оценка | факт | `nocond`+`sigmoid` | `cond`+`sigmoid` |
|---|---|---|---|
| 2 | 2.0% | 5.1% (+3.1) | 7.8% (+5.8) |
| 3 | 32.5% | 23.4% (−9.1) | 22.1% (−10.5) |
| 4 | 25.7% | 31.8% (+6.1) | 26.6% (+0.9) |
| 5 | 39.8% | 39.7% (−0.1) | 43.5% (+3.7) |
| сумма отклонений | | 18.4 п.п. | 21.0 п.п. |

Все конфигурации на фиксированном семействе занижают долю троек на 6–10 п.п.
и завышают долю двоек в 2–4 раза. Причина — форма самих `f`-функций: с
константами `(1−x)³` и `10x²` они не воспроизводят распределение с очень
малой долей двоек и высокой долей троек.

Семейства со свободными параметрами устраняют это смещение: `tilted` и
`ordered` дают по 8 попаданий из 8 в обоих семестрах.

| оценка | факт сем 1 | `ordered` | факт сем 2 | `ordered` |
|---|---|---|---|---|
| 2 | 1.99% | 2.00% | 2.32% | 2.27% |
| 3 | 32.5% | 34.5% | 27.9% | 28.2% |
| 4 | 25.7% | 25.7% | 28.5% | 28.7% |
| 5 | 39.8% | 37.9% | 41.2% | 40.8% |

### Выбор конфигурации по умолчанию

`ordered` + `sigmoid`. Основания: воспроизведение распределения оценок
(8 из 8), лучшая позиция по LOO на семестре 2 и наиболее надёжная
LOO-оценка (2 наблюдения с высоким Парето-k против 6–18), сходимость без
замечаний на обоих семестрах.

`tilted` превосходит его по выборочным метрикам и по LOO на семестре 1, но
его трасса на семестре 2 не сошлась, а высокое число точек с Парето-k > 0.7
снижает доверие и к его LOO-оценке.

## Тесты

```bash
pytest
```

`test_model.py` проверяет свойства, которые должны сохраняться при правках
формул: нормировку `f_2..f_5`, зеркальные симметрии, монотонность ожидаемой
оценки по способности и по сложности, принадлежность всех формул `ratio`
отрезку `[0, 1]`, распознавание chi-square эталонов, сохранение концентрации
приора, а также свойства альтернативных семейств правдоподобия.

`test_numpy_matches_pymc.py` сверяет numpy-реализации правдоподобия с самими
PyMC-моделями. Без этой проверки `validate.py` вычислял бы предсказательные
метрики по одной формуле, а MCMC работал бы по другой, и сравнение семейств
было бы недостоверным. Там же зафиксировано закрепление среднего порога
`ordered`.
